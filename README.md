# Site web de l'École de l'innovation en Outaouais

Site statique (HTML, CSS, images) publié avec GitHub Pages.

- `index.html` : page d'accueil
- `assets/` : images optimisées, logo et vidéo

Pour modifier le site : éditer les fichiers puis publier un commit sur la branche `main`. Le site en ligne se met à jour automatiquement en une minute environ.
